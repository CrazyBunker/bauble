# Балансовый Проверщик

Приложение для контроля баланса на yarurf.ru с уведомлениями Telegram.

## Требования
- Go 1.16+

## Установка
```bash
make yarurf-balance-checker
```

## Конфигурация
Создайте `config.yaml`:
```yaml
user:
  login: "ваш_логин"          # Логин от личного кабинета yarurf.ru
  password: "ваш_пароль"      # Пароль от личного кабинета yarurf.ru

templates:
  high_balance: "Баланс: %.2f (всё хорошо)"     # Шаблон при balance/cost > 3
  low_balance: "Внимание! Баланс: %.2f (ниже нормы)"   # Шаблон при balance/cost ≤ 3

cost: 36                       # Стоимость в рублях за 1 день (для расчёта дней)

notify:
  bot_token: "токен телеграмма"   # Токен Telegram-бота (@BotFather)
  chat:                            # Список ID чатов для уведомлений
    - 1234567890
  time:                            # Время отправки уведомления
    hour: 12                       # Час (0-23)
    minute: 0                      # Минута (0-59)

api_url: "https://yarurf.ru/api/lk"  # URL API для проверки баланса
```

## Использование
### Базовый запуск
```bash
./yarurf-balance-checker
```
### С указанием конфигурации
```bash
./yarurf-balance-checker -config /path/to/config.yaml
```

## Примеры форматов вывода
- Если `баланс / cost > 3` → шаблон high_balance
- Если `баланс / cost <= 3` → шаблон low_balance

Примеры:
```
Баланс: 150.00 (всё хорошо)  # При остатке на балансе > 3 дней
Внимание! Баланс: 80.00 (ниже нормы)  # При остатке на балансе < 3 дней
```

## Флаги
- `-config` – путь к файлу конфигурации (по умолчанию config.yaml)

## Тесты
```bash
go test ./cmd/yarurf-balance-checker/
```

## Логика работы
1. Проверяет текущую сессию по cookies.
2. Если сессия недействительна, выполняет авторизацию.
3. Производит запрос баланса.
4. Выводит результат в указанном формате, исходя из количества дней до истечения текущего баланса.
5. Завершает работу.
